# 🛒 shopping-listapp

바닐라 HTML/CSS/JavaScript로 만든 간단한 쇼핑 리스트 웹 앱입니다.

## 기능

- 항목 추가 / 체크 / 삭제
- 체크된 항목 일괄 비우기
- `localStorage` 기반 자동 저장 (새로고침해도 유지)
- 다크 모드 자동 대응 (`prefers-color-scheme`)
- 모바일 화면 대응

## 사용법

`shopping-list.html` 파일을 브라우저에서 열면 됩니다. 별도의 빌드나 서버가 필요 없습니다.
